# Simplified Chinese glossary (简体中文术语表)

Shared terminology for all Chinese content, so that every cocktail page uses the same words.

## Labels
- Classic → 经典 · Modern → 现代 · Illustration → 插画
- IBA → 国际调酒师协会（IBA） · Difford's Guide, PUNCH, CLASS, Drinks International → keep the English names
- garnish → 装饰 · glass → 杯型 · ice → 冰 · method → 做法 · serve up (no ice) → 不加冰（净饮）

## Style
- Write natural, concise Simplified Chinese for home bartenders. Use full-width punctuation（，。：；“”）.
- Keep people's names in Latin script (e.g. Sam Ross). Keep bar names in their original form. Translate city names (New York → 纽约, London → 伦敦).
- Keep years and numbers as digits. Never add facts that aren't in the English text, and keep every hedge ("traditionally", "disputed", "about").
